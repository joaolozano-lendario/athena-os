# 09 — GENIUS LAYER

> **"Perspectivas certas revelam verdades ocultas."**

---

## VISÃO GERAL

A Genius Layer é a camada de inteligência contextual que ativa a configuração cognitiva ideal para cada projeto.

---

## CONCEITO CENTRAL

```
INTENT → NATURE DETECTION → COGNITIVE KIT → DREAM TEAM → LENSES
```

---

## NATURE CODES

| Code | Domínio |
|------|---------|
| COPY | Copywriting, persuasão |
| ARCH | Arquitetura de sistemas |
| META | Meta-sistemas, frameworks |
| DATA | Análise, insights |
| PROD | Produtividade, workflows |
| BRAND | Branding, posicionamento |
| LEARN | Educação, cursos |
| CODE | Desenvolvimento |
